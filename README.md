# Маленький цветочный сад — 2.0.0

Небольшая игра для Windows 10/11 x64. Запустите `dist/FlowerGarden.exe`: без меню, установки и дополнительных файлов.

## Клумбы и листики

В начале в каждом саду посажена **одна клумба**. Остальные пять — пустые участки с табличкой «Не посажено». Подойдите к цветущей клумбе и **удерживайте F две секунды**: над девочкой появится заполняющаяся шкала. Только полная шкала поливает все 12 цветов клумбы и выдаёт награду. Если отпустить F, отойти или начать поливать другую клумбу, незавершённая шкала сбросится.

Награда за каждую клумбу равна числу посаженных клумб **в текущем саду**: одна клумба — 1 листик за полив, две — по 2, три — по 3, вплоть до шести — по 6. Старые комбо заменены этой системой. Уже мокрые цветы повторной награды не дают.

Когда все посаженные клумбы политы, появляется поздравление. Нажмите **R**, чтобы начать следующий цикл полива: посаженные клумбы, баланс и покупки останутся. Так можно зарабатывать с единственной начальной клумбой и постепенно расширять сад.

Подойдите к продавцу в правом нижнем углу, нажмите **E**, затем **B** — купить цветы и засадить следующую клумбу текущего сада.

| Новая клумба | Цена в листиках |
| --- | --- |
| Вторая | 3 |
| Третья | 8 |
| Четвёртая | 18 |
| Пятая | 32 |
| Шестая | 50 |

**Лунный сад стоит 1500 листиков**. Покупка — клавиша **L**, переход между садами после покупки — **Tab**. В лунном саду звёздные цветы; клумбы покупаются отдельно, а баланс и наряды общие.

## Управление

- **WASD** — гулять.
- **F**, удерживать — поливать ближайшую посаженную сухую клумбу.
- **E** у продавца — открыть / закрыть лавку.
- **B** в лавке — купить цветы для следующей клумбы.
- **L** — купить лунный сад, **Tab** — сменить сад после покупки.
- **R** после полного полива — следующий цикл, **Enter** — закрыть поздравление.
- Кнопка **«Новая игра»**, **N** или **F2** — полный сброс с подтверждением.
- **Esc** — закрыть лавку, либо выйти из игры.

## Шляпки и лейки

В лавке клавиши **1–5** покупают и надевают вещи. Повторный выбор купленного бесплатный.

| Клавиша | Товар | Цена |
| --- | --- | --- |
| 1 | Соломенная шляпка | 4 |
| 2 | Панама с ромашкой | 8 |
| 3 | Звёздная шляпка | 12 |
| 4 | Медная лейка | 6 |
| 5 | Лунная лейка | 10 |

**6** — снять шляпку, **7** — обычная лейка. Все лейки поливают одинаково.

## Сохранение

Прогресс автоматически записывается в `%LOCALAPPDATA%\FlowerGarden\progress.dat`. Сохраняются баланс, наряды, покупка лунного сада, посаженные клумбы и законченные поливы. Незавершённая шкала не сохраняется. При ошибке записи появляется предупреждение. Запускайте одну копию игры одновременно.

При переходе с прошлых версий сохраняются листики, купленные наряды и доступ к лунному саду, если он был открыт. Для новой системы посадок каждый сад начинает с одной сухой клумбы. Новая игра по кнопке полностью сбрасывает и покупки, и баланс.

## Сборка и тесты

Нужен GCC из MinGW-w64:

```sh
./build.sh
```

Путь к компилятору можно задать через `CC`. На Windows с MinGW-w64:

```bat
x86_64-w64-mingw32-gcc src/garden.c -o FlowerGarden.exe -std=c11 -Os -Wall -Wextra -Werror -municode -mwindows -static -s -lgdi32 -luser32 -lm
```

Проверка игровой логики на Linux:

```sh
gcc -std=c11 -Wall -Wextra -Werror -fsanitize=address,undefined tests/game_test.c -o /tmp/garden-test
/tmp/garden-test
```

Тесты проверяют длительность и прерывание полива, запрет наград за пустые / мокрые клумбы, рост цен и наград, достижимость всей прогрессии заработком в игре, покупку лунного сада, наряды, сохранения и перенос старых форматов. Они не заменяют запуск графики и проверку Windows API на Windows.
