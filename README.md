# Маленький цветочный сад

Миниатюрная игра для Windows 10/11 (64 бит). Откройте `dist/FlowerGarden.exe`: игра начинается сразу, без меню и установки. Все рисунки создаются программно, дополнительные файлы не нужны.

- **WASD** — ходить (латинские клавиши, независимо от раскладки).
- **F**, удерживать — поливать цветы в радиусе вокруг девочки. Политые цветы раскрываются чуть больше и отмечаются голубой каплей.
- **Esc** — закрыть окно.

В саду 72 цветка в шести цветных группах. Счётчик показывает, сколько цветов полито. При новом запуске сад начинается заново.

## Сборка

Нужен MinGW-w64 с GCC. В Linux:

```sh
./build.sh
```

Можно указать путь к компилятору через `CC`. В Windows с MinGW-w64:

```bat
x86_64-w64-mingw32-gcc src/garden.c -o FlowerGarden.exe -std=c11 -Os -Wall -Wextra -Werror -municode -mwindows -static -s -lgdi32 -luser32 -lm
```

Исходник: `src/garden.c`. Используется только стандартный Windows API (GDI), без движка и сторонних библиотек.
