# Маленький цветочный сад

Миниатюрная игра для Windows 10/11 (64 бит). Откройте `dist/FlowerGarden.exe`: игра начинается сразу, без меню и установки. Все рисунки создаются программно, дополнительные файлы не нужны.

- **WASD** — ходить (латинские клавиши, независимо от раскладки).
- **F**, удерживать — поливать цветы в радиусе вокруг девочки. Политые цветы раскрываются чуть больше и отмечаются голубой каплей.
- **E** — поговорить с продавцом у лавочки в правом нижнем углу сада.
- **L** — купить лунный сад за **30 листиков** и сразу перейти туда.
- **Tab** — переключаться между садами после покупки.
- **Enter** — закрыть поздравление после полива всех цветов.
- **R** — вырастить новые цветы в полностью политом саду; листики и покупка сохраняются.
- **N**, **F2** или кнопка **«Новая игра»** внизу справа — начать новую игру с полным сбросом прогресса (после подтверждения).
- **Esc** — закрыть окно.

В каждом саду 72 цветка в шести цветных группах. В лунном саду — звёздные цветы с восемью лепестками и светлой серединкой. Когда весь сад полит, появляется окно с поздравлением.

**Комбо:** один полив захватил минимум два ранее сухих цветка — получаете **2 листика** независимо от размера группы. При удержании F полив происходит каждые 0,4 секунды. Повторный полив уже мокрых цветов не приносит награду. Листики общие для двух садов.

Игра автоматически сохраняет баланс, покупку сада, шляпки и лейки, выбранный наряд, текущую локацию и политые цветы обоих садов в `%LOCALAPPDATA%\FlowerGarden\progress.dat`. При ошибке сохранения внизу окна появляется сообщение. Для игры без потери прогресса запускайте только одну копию приложения.

## Новая игра

Нажмите кнопку **«Новая игра»** внизу справа либо клавишу **N** или **F2** в саду, в лавке или на экране поздравления. На некоторых клавиатурах F2 доступна через **Fn + F2**; кнопка мышью и N работают независимо от функционального ряда. В заголовке обновлённого окна указана версия **1.3.1**. Игра спросит подтверждение; по умолчанию выбрано «Нет». При согласии сбрасываются листики, купленные вещи, выбранный наряд, открытые локации и полив обоих садов. Вы сразу окажетесь в первом саду с обычной лейкой. Сброс сохраняется на диск, удалять файлы вручную не нужно. Если сохранение недоступно, игра покажет предупреждение.

Клавиша **R** по-прежнему только выращивает цветы заново в завершённом саду и сохраняет покупки и баланс.

## Лавка и наряды

Подойдите к лавочке в правом нижнем углу и нажмите **E**. Пока лавка открыта, ходьба и полив приостановлены.

| Клавиша в лавке | Товар | Цена в листиках |
| --- | --- | --- |
| 1 | Соломенная шляпка | 4 |
| 2 | Панама с ромашкой | 8 |
| 3 | Звёздная шляпка | 12 |
| 4 | Медная лейка | 6 |
| 5 | Лунная лейка | 10 |

Повторный выбор купленной вещи бесплатный. **6** — снять шляпку, **7** — вернуть обычную лейку. **E** или **Esc** закрывают лавку. Шляпки и лейки меняют внешний вид; радиус полива одинаковый.

Цена нового сада теперь 30 листиков. Если вы уже открыли его в предыдущей версии, он останется открытым. Старое сохранение переносится автоматически: баланс и политые цветы не пропадут. Чтобы заработать ещё, завершите сад и нажмите **R** для нового цикла выращивания.

Окружение рисуется без внешних ресурсов: пучки травы, дорожки с камнями, деревянные прожилки забора, кусты с ягодами, земля на клумбах и тени.

## Сборка

Нужен MinGW-w64 с GCC. В Linux:

```sh
./build.sh
```

Можно указать путь к компилятору через `CC`. В Windows с MinGW-w64:

```bat
x86_64-w64-mingw32-gcc src/garden.c -o FlowerGarden.exe -std=c11 -Os -Wall -Wextra -Werror -municode -mwindows -static -s -lgdi32 -luser32 -lm
```

Исходник: `src/garden.c`. Используется только стандартный Windows API (GDI), без движка и сторонних библиотек.

## Проверка логики

На Linux с GCC (без Windows и графики):

```sh
gcc -std=c11 -Wall -Wextra -Werror -fsanitize=address,undefined tests/game_test.c -o /tmp/garden-test
/tmp/garden-test
```

Проверяются награды за комбо, защита от повторных наград, недостаток средств, однократная покупка, полив всего сада, повторное выращивание, независимость садов сериализация прогресса, покупки и бесплатное переодевание, перенос сохранений из старой версии. Эти тесты не заменяют проверку графики и файлового сохранения на Windows.
