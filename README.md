# Маленький цветочный сад — 2.1.0

Небольшая игра для Windows 10/11 x64. Запустите `dist/FlowerGarden.exe`: без меню, установки и дополнительных файлов.

## Клумбы и листики

В начале в каждом саду посажена **одна клумба**. Остальные пять — пустые участки с табличкой «Не посажено». Подойдите к цветущей клумбе и **удерживайте F две секунды**: над девочкой появится заполняющаяся шкала. Только полная шкала поливает все 12 цветов клумбы и выдаёт награду. Если отпустить F, отойти или начать поливать другую клумбу, незавершённая шкала сбросится.

Награда за каждую клумбу равна числу посаженных клумб **в текущем саду**: одна клумба — 1 листик за полив, две — по 2, три — по 3, вплоть до шести — по 6. Старые комбо заменены этой системой. Уже мокрые цветы повторной награды не дают.

После полива всех клумб игра продолжается без всплывающего окна. Чтобы начать новый день, подойдите к маленькому домику слева у дорожки и нажмите **E**. После короткой ночи все посаженные цветы в обоих садах снова ждут полива. Покупки, посадки и листики сохраняются, номер дня увеличивается. Спать можно в любой момент, даже если полит не весь сад; за сам сон листики не выдаются. Клавиша R больше не нужна.

Подойдите к продавцу в правом нижнем углу, нажмите **E**, затем **B** — купить цветы и засадить следующую клумбу текущего сада.

| Новая клумба | Цена в листиках |
| --- | --- |
| Вторая | 3 |
| Третья | 8 |
| Четвёртая | 18 |
| Пятая | 32 |
| Шестая | 50 |

**Лунный сад стоит 1500 листиков**. Покупка — клавиша **L**, переход между садами после покупки — **G**. В лунном саду звёздные цветы; клумбы покупаются отдельно, а баланс и наряды общие.

## Управление

- **WASD** — гулять.
- **F**, удерживать — поливать ближайшую посаженную сухую клумбу.
- **E** у продавца — открыть / закрыть лавку; у домика — поспать до следующего дня.
- **B** в лавке — купить цветы для следующей клумбы.
- **L** — купить лунный сад, **G** — сменить сад после покупки.
- **Tab** — открыть / закрыть памятку по кнопкам. Во время чтения игра приостановлена.
- Кнопка **«Новая игра»**, **N** или **F2** — полный сброс с подтверждением.
- **Esc** — закрыть лавку, либо выйти из игры.

## Шляпки и лейки

В лавке клавиши **1–5** покупают и надевают вещи. Повторный выбор купленного бесплатный.

| Клавиша | Товар | Цена |
| --- | --- | --- |
| 1 | Соломенная шляпка | 4 |
| 2 | Панама с ромашкой | 8 |
| 3 | Звёздная шляпка | 12 |
| 4 | Медная лейка | 6 |
| 5 | Лунная лейка | 10 |

**6** — снять шляпку, **7** — обычная лейка. Все лейки поливают одинаково.

## Сохранение

Прогресс автоматически записывается в `%LOCALAPPDATA%\FlowerGarden\progress.dat`. Сохраняются баланс, наряды, покупка лунного сада, посаженные клумбы, законченные поливы и номер дня. Незавершённая шкала не сохраняется. При ошибке записи появляется предупреждение. Запускайте одну копию игры одновременно.

При обновлении с версии 2.0 сохраняются все клумбы, полив, баланс и покупки; отсчёт дней начинается с первого. При переходе с версий до 2.0 сохраняются листики, наряды и доступ к лунному саду, а посадки начинают с одной клумбы в каждом саду. Новая игра по кнопке полностью сбрасывает и покупки, и баланс.

## Сборка и тесты

Нужен GCC из MinGW-w64:

```sh
./build.sh
```

Путь к компилятору можно задать через `CC`. На Windows с MinGW-w64:

```bat
x86_64-w64-mingw32-gcc src/garden.c -o FlowerGarden.exe -std=c11 -Os -Wall -Wextra -Werror -municode -mwindows -static -s -lgdi32 -luser32 -lm
```

Проверка игровой логики на Linux:

```sh
gcc -std=c11 -Wall -Wextra -Werror -fsanitize=address,undefined tests/game_test.c -o /tmp/garden-test
/tmp/garden-test
```

Тесты проверяют длительность и прерывание полива, запрет наград за пустые / мокрые клумбы, рост цен и наград, достижимость всей прогрессии через полив и сон, смену дня без потери покупок, покупку лунного сада, наряды, сохранения и перенос старых форматов. Они не заменяют запуск графики и проверку Windows API на Windows.
